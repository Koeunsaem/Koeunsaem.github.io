01 / FEATURED PROJECT

AI 자막 생성·번역
스트리밍 플랫폼

BACKENDAI PIPELINE2025

배경

기존 LMS에 AI 자막 생성과 다국어 번역 기능을 더하는 산학협력 프로젝트였습니다. AI 결과를 만드는 것뿐 아니라 기존 MVC 시스템과 새 React 화면 사이에서 영상·자막 데이터가 안정적으로 오가야 했습니다.

문제

프론트엔드와 기존 백엔드의 응답 방식이 달랐고, AI가 만든 SRT 파일은 HTML5 영상에서 바로 재생할 수 없었습니다. 같은 영상에 자막 생성을 반복 요청하면 불필요한 연산도 발생했습니다.

설계

각 시스템을 다시 만드는 대신 경계에서 데이터를 표준화했습니다. React가 필요한 데이터를 JSON으로 제공하고, AI 처리 결과는 파일 단위로 저장·재사용하며, 재생 직전 웹 표준 형식으로 변환하는 흐름을 설계했습니다.

구현

  • 영상·자막·DB 정보를 전달하는 JSON API 구현
  • 자막 생성 요청 → AI 서버 → 결과 저장 → 화면 제공 흐름 연결
  • 생성 파일 재사용으로 동일 영상의 반복 처리 방지
  • SRT를 VTT로 변환해 HTML5 영상 재생 환경과 호환

결과

Faster Whisper 기반 STT, 도메인 사전 후처리, MarianNMT 번역 결과가 실제 영상 화면에서 동작하는 서비스 흐름을 완성했습니다. 연구 결과는 한국정보처리학회 학술대회논문집에 게재했습니다.

배운 점

좋은 기능은 모델 성능만으로 완성되지 않습니다. 데이터 형식과 호출 순서, 저장 방식, 재생 환경까지 빈틈없이 연결되어야 사용자에게 자연스러운 경험이 됩니다.

02 / AI PROJECT

상품 카테고리
자동 분류·분석 도구

AI MODELINGDATA2025
2.28M학습 데이터
198분류 카테고리
0.94Macro F1

배경

온라인 커머스의 대규모 상품을 사람이 일일이 분류하는 반복 업무를 줄이기 위해, 상품명 기반 자동 분류 모델과 성능 분석 도구를 개발했습니다.

문제

카테고리별 데이터 수의 차이가 커 Accuracy만으로는 소수 카테고리의 취약점을 놓칠 수 있었습니다. 제가 실험한 BERT는 학교 AI 서버의 제한된 GPU 메모리에서 학습이 반복 중단돼 운영 가능한 비교 결과를 만들기 어려웠습니다.

설계

전체 정확도와 함께 Macro F1-Score를 주요 지표로 삼아 데이터가 적은 카테고리까지 평가하도록 기준을 세웠습니다. 운영 환경에서 비교 가능한 로지스틱 회귀와 LSTM을 최종 후보로 정했습니다.

구현

BERT 전용 토크나이저를 적용해 모델 학습을 실험하고, 팀이 개발한 로지스틱 회귀와 LSTM을 동일 조건에서 비교했습니다. 모델별 성능과 카테고리별 취약점을 확인하는 웹 분석 도구도 구현했습니다.

결과

팀은 로지스틱 회귀의 정규화 강도를 조정해 Macro F1-Score를 0.91에서 0.94로 높였습니다. 모델별 성능과 카테고리별 취약점을 확인하는 웹 도구도 완성해 두 차례 경진대회에서 수상했습니다.

배운 점

복잡한 모델 자체보다 데이터 특성과 자원 제약을 정확히 읽는 것이 중요했습니다. AI가 실제 업무 개선으로 이어지려면 재현 가능한 비교 기준과 운영 가능한 선택이 필요합니다.

03 / GLOBAL PROJECT

BuyCycle

살까, 팔까—제품의 다음 선택을 돕는 AI 의사결정 서비스

AI AGENT2-PERSON TEAMSJSU

배경

제품을 구매하기 전과 보유한 뒤의 선택을 한곳에서 지원하는 서비스를 2인 팀으로 기획했습니다.

문제

구매 단계에서는 가격과 사용 가치를, 보유한 뒤에는 수리·교체·판매 시점을 각각 찾아봐야 했습니다. 판단에 필요한 근거가 흩어져 있어 사용자가 선택지를 직접 정리해야 했습니다.

설계

자연어 질문을 AI Agent가 구조화하고 Gemini와 검색 데이터를 연계해 선택지를 비교하도록 분석 흐름을 설계했습니다. 결과에는 근거와 유의사항을 포함하고 출력 형식을 일정하게 맞췄습니다.

구현

구매·대여·대기와 수리·교체·판매를 비교하는 웹 흐름을 구현하고, 분석 결과를 사용자의 아이템·결정 이력과 연결했습니다.

결과

제품의 구매 전후 의사결정을 하나의 흐름에서 지원하는 웹 서비스를 완성했습니다.

배운 점

AI에 자유롭게 답하게 하기보다 필요한 정보와 출력 형식을 명확히 구조화할수록 결과를 서비스에서 안정적으로 활용할 수 있었습니다. 또한 근거를 확인할 수 있는 구조와 사용자 데이터 보호가 AI 서비스의 신뢰를 만든다는 점을 배웠습니다.
